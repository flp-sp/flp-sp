* **TucoOS:** Custom x86 operating system built in C and Assembly, featuring a custom bootloader, kernel shell, Makefile automation, and a custom FAT-based file system (TOFS).
* **Bread of Life:** Desktop study application built in Python (CustomTkinter) integrated with Google Gemini API for real-time AI assistance.
* **Clinic Management System:** Flask web application designed for small clinics featuring persistent data storage, input validation, and clean interface design.
* **Mobile Expense Splitter:** Android app built with Java and Material Components, developed using Spec-Driven Development (SDD) via OpenCode.
* **E-Commerce Landing Page:** Custom landing page with automated WhatsApp ordering and DNS setup.
